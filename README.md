# Soumyadeep Bhattacharya — Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Included
- Personal profile and contact details
- Professional summary
- Technical skills including WordPress website development
- Education and certifications
- Karate and NCC achievements
- Featured GitHub projects and secondary projects
- Responsive layout for desktop, tablet and mobile
- Scroll/reveal animations
- Local profile image and resume PDF

## Run locally
Open `index.html` directly, or use VS Code Live Server.

No Node.js, npm, PHP or database is required for this static portfolio.
